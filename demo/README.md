# Demo assets

Sample inputs for exercising PlanAround's AI extraction paths without using real, private student material.

## `sample-assignment.txt`

A synthetic assignment brief for the "paste text" and "assignment AI analysis" flows. It includes a title, a deadline, a module weighting, and several rubric tasks with marks, so extraction can be checked end to end (title, deadline, weight, tasks, marks, complexity).

It is not tuned to exploit parser/model edge cases; it represents a plausible student brief.

## Sample timetable

The existing sample timetable PDF lives at [`public/semester-1-timetable.pdf`](../public/semester-1-timetable.pdf) and is generated by [`scripts/create_demo_timetable.py`](../scripts/create_demo_timetable.py). Use it for the onboarding/timetable-import step of a demo.
